01 — O que é programação?

Programar é escrever instruções para que o computador execute tarefas. A programação é usada para criar sites, jogos, aplicativos, ferramentas e sistemas.

  • Front-end: a parte do site que o usuário vê e utiliza.
  • Back-end: a parte que processa informações no servidor.
  • Banco de dados: armazena informações organizadas.
  • Linguagem: uma forma de escrever instruções para executar tarefas.

Vamos começar com desenvolvimento web, porque você pode visualizar seus primeiros resultados no navegador.

Atividade: escreva três coisas que gostaria de criar usando programação.
02 — Lógica de programação

Um algoritmo é uma sequência de passos para resolver um problema.

Para somar dois números, por exemplo, você recebe os valores, soma e mostra o resultado.

Os conceitos básicos são:

  • Variáveis: guardam valores.
  • Condições: permitem tomar decisões.
  • Repetições: executam instruções várias vezes.
  • Funções: agrupam instruções reutilizáveis.
let numero = 10;

if (numero > 0) {
  console.log("Número positivo");
} else {
  console.log("Número zero ou negativo");
}
Atividade: altere o número e observe como a mensagem muda.
03 — HTML: estrutura dos sites

HTML organiza o conteúdo da página, incluindo títulos, parágrafos, imagens, links e botões.

<h1>Meu primeiro site</h1>
<p>Estou aprendendo programação!</p>
<a href="https://example.com">Meu link</a>
  • h1: título principal.
  • p: parágrafo.
  • a: link.
  • img: imagem.
  • button: botão.

Uma página completa utiliza estruturas como html, head e body.

Atividade: crie um título, um parágrafo e um link sobre um assunto de que você gosta.
04 — CSS: cores, estilos e layouts

CSS controla a aparência de um site: cores, fontes, tamanhos, alinhamento, espaçamento e adaptação para celular.

body {
  background: #f4f7fc;
  font-family: Arial, sans-serif;
}

h1 {
  color: #2563eb;
  text-align: center;
}

button {
  padding: 12px 20px;
  border-radius: 8px;
}

Você também pode aprender Flexbox, Grid e media queries para construir layouts organizados e responsivos.

Atividade: mude as cores do exemplo e deixe o botão arredondado.
05 — JavaScript: interatividade

JavaScript permite responder a cliques, calcular valores, validar formulários e atualizar elementos da página.

const nome = "MERCADÃO";

function cumprimentar(pessoa) {
  return "Olá, " + pessoa + "!";
}

console.log(cumprimentar(nome));

Estude variáveis, tipos de dados, operadores, condições, repetições, funções, arrays e objetos.

O DOM permite que o JavaScript encontre e modifique elementos HTML.

document.querySelector("button")
  .addEventListener("click", function() {
    alert("Você clicou no botão!");
  });
Atividade: crie um botão que mostre uma mensagem quando for clicado.
06 — Python: introdução

Python é usado em automação, análise de dados, desenvolvimento web e outras áreas.

nome = input("Qual é o seu nome? ")
print("Olá,", nome)

numero = int(input("Digite um número: "))

if numero % 2 == 0:
    print("Número par")
else:
    print("Número ímpar")

Estude variáveis, condições, repetições, listas, dicionários e funções.

Para executar Python, utilize uma instalação do Python ou um ambiente online compatível. Ele não é executado diretamente pelo navegador como HTML.

Atividade: faça um programa que pergunte o nome e mostre uma saudação.
07 — Git e GitHub

Git registra alterações no código. GitHub permite guardar projetos online e colaborar com outras pessoas.

git init
git add .
git commit -m "Meu primeiro projeto"
git status
  • git init: inicia um repositório.
  • git add: prepara alterações.
  • git commit: registra alterações.
  • git status: mostra o estado dos arquivos.
  • git push: envia alterações para um repositório remoto configurado.

O GitHub Pages pode publicar sites estáticos. Sistemas que precisam de servidor e banco de dados exigem uma solução de hospedagem adequada.

Atividade: organize um projeto em uma pasta e crie um repositório para guardar seus arquivos.
08 — Banco de dados e SQL

Bancos de dados guardam informações para que os sistemas possam consultar, inserir e atualizar dados.

CREATE TABLE alunos (
  id INTEGER PRIMARY KEY,
  nome TEXT,
  curso TEXT
);

INSERT INTO alunos (id, nome, curso)
VALUES (1, 'Ana', 'Programação');

SELECT * FROM alunos;

Aprenda tabelas, colunas, linhas, chaves, consultas e operações de atualização.

Atividade: planeje uma tabela para registrar alunos, cursos e datas de matrícula.
09 — Back-end e APIs

O back-end processa dados no servidor. Uma API permite que sistemas troquem informações.

Estude requisições HTTP, rotas, JSON, validação e tratamento de erros. Node.js permite executar JavaScript no servidor; Python também pode ser usado para construir back-ends.

fetch("https://jsonplaceholder.typicode.com/posts/1")
  .then(resposta => resposta.json())
  .then(dados => console.log(dados))
  .catch(erro => console.log("Erro:", erro));

O exemplo utiliza uma API de demonstração. Em projetos reais, trate falhas e valide os dados recebidos.

Atividade: explique com suas palavras a diferença entre front-end e back-end.
10 — Segurança e boas práticas
  • Valide os dados recebidos pelos formulários.
  • Não exponha senhas, tokens ou chaves privadas.
  • Use autenticação adequada em sistemas com contas.
  • Trate erros sem revelar informações sensíveis.
  • Faça cópias de segurança quando necessário.
  • Escreva código organizado e teste as funcionalidades.

Segurança faz parte do desenvolvimento desde o início, não apenas quando o projeto fica pronto.

Atividade: liste três cuidados importantes antes de publicar um site.
11 — Depuração e resolução de erros

Depurar significa investigar por que um programa não funciona como esperado.

  1. Leia a mensagem de erro.
  2. Confira a linha indicada.
  3. Verifique nomes, parênteses e chaves.
  4. Teste uma alteração por vez.
  5. Utilize o console para conferir valores.
let resultado = 10 / 2;
console.log(resultado); // 5
Atividade: crie uma variável e use console.log() para conferir seu valor.
12 — Portfólio e próximos passos

Um portfólio reúne projetos que demonstram suas habilidades. Comece com coisas pequenas e evolua conforme aprende.

  • Uma página pessoal com HTML e CSS.
  • Uma calculadora com JavaScript.
  • Um quiz com pontuação.
  • Uma lista de tarefas.
  • Um programa simples em Python.

Descreva o que cada projeto faz, as tecnologias utilizadas e o que você aprendeu.
